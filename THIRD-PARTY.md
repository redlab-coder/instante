# Recursos de terceiros

- [Pillow](https://github.com/python-pillow/Pillow): processamento de imagens, licença HPND.
- [pystray](https://github.com/moses-palmer/pystray): bandeja do Windows, LGPL-3.0.
- [OpenCV](https://github.com/opencv/opencv): detecção local, Apache-2.0 na série distribuída. Consulte as licenças incluídas no pacote OpenCV para suas dependências.
- [YuNet / OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet): modelo `face_detection_yunet_2023mar.onnx`, MIT. A licença acompanha o modelo em [assets/models/YUNET-LICENSE.txt](assets/models/YUNET-LICENSE.txt).
- [NumPy](https://github.com/numpy/numpy): matrizes usadas na detecção, BSD-3-Clause.

O modelo é distribuído com o aplicativo e processa as imagens localmente. As ilustrações das capturas são geradas pelo script de demonstração do projeto. Fontes do sistema usadas para gerar essas imagens não são distribuídas como arquivos de fonte.
