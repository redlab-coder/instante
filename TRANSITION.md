# Polaroid Editor no RedLab Editor

O desenvolvimento passou para o [RedLab Editor](https://github.com/redlab-coder/redlab-editor), que reúne Bottons Editor e Polaroid Editor com downloads e atualizações independentes.

Esta é uma release de transição para os clientes já instalados. O instalador é uma cópia byte a byte do arquivo aprovado e publicado na [release oficial Polaroid Editor 1.1.2](https://github.com/redlab-coder/redlab-editor/releases/tag/polaroid-v1.1.2). O manifesto mantém o formato esperado pelo atualizador anterior.

Salve seu lote e encerre normalmente para aplicar a atualização disponível. O nome, a identidade da instalação e os lotes continuam os mesmos; as próximas atualizações virão do novo repositório.

O código do novo programa está na tag `polaroid-v1.1.2` do RedLab Editor. O código neste repositório fica preservado como histórico anterior à integração.
