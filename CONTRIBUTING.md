# Contribuir

Relate problemas com a versão do Polaroid Editor, passos para reproduzir e resultado esperado. Use imagens de demonstração e não publique fotos de clientes.

Mudanças devem preservar as medidas, a faixa de corte, a proporção das imagens e o funcionamento local. Para alterações visuais, inclua uma captura real com conteúdo publicável. Consulte o [guia de desenvolvimento](docs/development.md) e execute as verificações relacionadas.

O projeto segue a experiência de uso e a organização do [Moldura](https://github.com/redlab-coder/moldura), com um motor próprio para polaroids.
